# Objetivo

Como trabajo final de la materia Análisis Exploratorio de Datos (AED), el objetivo fue crear un modelo que pudiera predecir la baja de un cliente de un banco X en una ventana de 2 meses (target = baja + 2)

La base original es confidencial y fue autorizada a utilizarse sólo con fines educativos. Es por eso que en el repositorio no se encuentra la base Attrition.
